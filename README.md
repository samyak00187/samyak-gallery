# Samyak Gallery

An Electron-powered 3D photo gallery. The gallery also runs in a web browser.

## Try it online

https://samyak00187.github.io/samyak-gallery/

The GitHub Actions workflow builds and publishes the browser version to GitHub
Pages whenever changes are pushed to `main`.

## Run the desktop app

1. Install Node.js (LTS).
2. Run `npm install`.
3. Run `npm start` to launch the app.
4. Run `npm run dist` to build the Windows portable executable in `dist`.
