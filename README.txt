Build the Samyak .exe (do this on a Windows PC)

1. Install Node.js (LTS) from https://nodejs.org
2. Open this folder in a terminal (PowerShell or Command Prompt)
3. Run:  npm install
4. Run:  npm run dist
5. Your app is in the "dist" folder: Samyak 1.0.0.exe (single file, no install needed)

Quick test without building:  npm start
